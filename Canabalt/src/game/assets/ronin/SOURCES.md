# Ronin character

Artist: **OcO**

Source: https://oco.itch.io/cyberpunk-character-pack-2

Downloaded the free `Ronin.zip` from the artist's official itch.io page on
2026-09-28. PNG files are unmodified. Each gameplay sprite cell is 64 × 64.

The artist permits using and modifying these characters in personal and
commercial projects, and prohibits reselling the assets individually.
The original download does not contain a separate license file.

Only Idle (8 frames), Run (10), Jump (15), and Death (16) are included in the
itch.io build. The Jump strip includes takeoff, ascent, descent, and landing
poses; the renderer follows vertical velocity rather than playing the whole
strip on a fixed timer while airborne.

All cells use the same origin (32, 45). Transparent margins are preserved so
animation frames do not wobble when switching states.
